# Map the features

When: the Work's `Several features` line is yes.

Steps:

1. Name each job the Goal needs done: who, in what situation, wanting what. Each is a Flow with its `Trigger`, first step and last step.
2. Walk each Flow and add a step wherever the work passes to someone else.
3. Beside each step, name the Feature that delivers it.
4. A step with no Feature is a gap. Ask: needed, done today, or out of scope?
5. A Feature beside no step has no job yet. Ask who it is for.

Stop when: every step has a Feature or an answer, and every Feature names a Flow.

Output: draft Flows, each Feature's `Flow` line and `### Flow steps`, and an `### Out of scope` line or a Question for each gap.
